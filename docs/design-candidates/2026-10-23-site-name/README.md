## 本人の選択（要旨。原文は ops に記録）

- 名前は「works」。B の形から上の「Yoshida」を外し、名前の下に小さく「Naoki Yoshida / n-yoshida-dev」と添える（GitHub や Qiita のアカウント名を書くように）
- 表紙の見せ方は A か B で迷い、開いたときの動きは C
- 名前の下の一言（「作ったアプリや道具と、書いた記事を置いています。」）は要らない

どの案もそのままではなく、B の組み方をもとに本人が組み替えた形になった。

## 審査役 2 つのおすすめ（作り手を知らない AI）

- 審査役 1（Fable）：名前・表紙とも C。A と C が独立に同じ名前に行き着き、C のほうが定数の分け方と大きさが決まっている（`judges/fable.md`）
- 審査役 2（Codex）：名前は B。表紙は B を軸に、目次は C の今のままの形を組み合わせる（`judges/codex.md`）

2 つのおすすめは割れた。本人の選択は、どちらのおすすめとも違う組み合わせ。
