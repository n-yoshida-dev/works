# ブリーフ：works のサイトの名前と表紙

## お題

個人の制作物を紹介する静的サイト（リポジトリ名 works）の、サイトの名前を何にするか。
今は本名のローマ字「Naoki Yoshida」がサイトの名前で、トップの表紙の大きな見出しにもなっている。名前の案と、その名前を表紙でどう見せるかを、表紙の見本で示す。
1 案につき名前は 1 つ。表紙の見本はその名前で描く。代わりの名前の候補があれば、aim.md に理由付きで添える。

## 誰のためのものか

- 本人が作ったアプリ・開発の道具・開発と学習の仕組み・技術記事に興味を持った人。GitHub や Qiita のリンクから来て、PC かスマホで開く
- 訪問者が自分の AI（ChatGPT など）にサイトを読ませることもある（`llms.txt` と Ask AI のページ）
- 本人（サイトの持ち主）。自分のサイトとして名前に納得できること

## 事実

- サイトの名前は `src/site.ts` の `SITE.name` / `SITE.title` で、次の場所に出る（`grep` の結果）：表紙の見出し（`index.astro` の `<h1>`）、ブラウザのタブの題名（各ページは「ページ名 — 名前」、トップは名前だけ。`og:title`・`twitter:title` も同じ文字列）、OGP の `og:site_name`、左の目次の一番上、フッターの著作権表示、`llms.txt` と `llms-full.txt` の見出し、Ask AI の依頼文の中の名前
- `SITE.name` を通らずに名前が出る所：OG 画像（`scripts/generate-og.mjs` 12 行目に直書き。`public/og.png` を作る）、`public-profile/profile.md` の `description`（「Naoki Yoshida が作ったアプリや道具と…」。トップの説明文・`og:description`・`llms.txt` の About の行に出る）
- 表紙（開いた直後の 1 画面）は、名前・一言・目次だけ。PC は左に名前と一言、右に目次の 2 列。スマホは名前・一言・目次が縦に並び、目次は 2 列（材料の `cover-1280.png`・`cover-375.png`）。目次の各項目には件数と ■ の図が付く
- DESIGN.md の表紙の記述（「要点 3 行」がある）は古い。2026-10-22 に要点 3 行を外した。今の姿は `index.astro` とスクリーンショットが正しい
- 表紙の一言は `public-profile/profile.md` の `tagline`：「作ったアプリや道具と、書いた記事を置いています。」
- トップの節は About / Projects / Tools / Systems / Writing / Ask AI
- GitHub のアカウント名（ハンドル名）は `n-yoshida-dev`。GitHub のプロフィールの表示名と、このリポジトリのコミットの作者名は「Naoki Yoshida」（2026-10-23 に `gh api users/n-yoshida-dev` と `git log` で確認）
- 公開先は Vercel の予定で、プロジェクト名は `n-yoshida-works`（URL は `n-yoshida-works.vercel.app` の見込み）。リポジトリ名は `works`
- 2026-10-20 の判断台帳ではサイト名を「Naoki Yoshida」のままとした。今回のお題はその部分を問い直すもの。DESIGN.md の「題名」の行はその古い結論

- 見た目の決まりは `DESIGN.md`（値の正本は `src/styles/global.css`）

## 決まり（変えてはいけないこと）

- 文面（名前・一言・タブの題名・OG 画像の名前・説明文）を変えたら、変えた所と元の文を aim.md に並べて書く
- Private のリポジトリの原文・個人の事実を案に書かない
- このサイトはキャリアの情報（仕事の内容・技術の到達度の評価・取得した認定・職種の肩書き）を載せない。名前・一言にも入れない
- 色は DESIGN.md の 7 つの色の範囲で描く。Web フォントを読み込まない（OS の書体だけ）。グラデーション・影・光るカードを使わない。青はリンクにだけ使う
- 表紙に置くのは、名前・一言・目次。題名と持ち主の名前を両方置く場合は、合わせて「名前」の枠と数える
- 目次の 6 項目・並び順・件数と ■ の図は残す
- どの名前にしても、サイトのどこかから持ち主（本名かハンドル名）が分かること。今、GitHub のリンクは表紙の直後のリンクカードと、PC の左の目次の下にある
- リポジトリ名・Vercel のプロジェクト名・URL はこのお題の外（変えない前提で考える）
- OG 画像は、出す名前の文言だけを変える対象。色と配置は今のまま
- 見本は明るい画面だけでよい（色は、暗い画面の値が DESIGN.md にある前提で選ぶ）

## 変えてよいこと

- サイトの名前（本名・ハンドル名・それ以外の名前。題名と持ち主の名前の組み合わせもよい）
- 名前と一言の見せ方（大きさ・順番・2 つの関係）。表紙の中の配置
- タブの題名・OG 画像に出す名前（表紙と変えてもよい）
- 一言の文面

## 節

1. サイトの名前
2. 表紙の見せ方
