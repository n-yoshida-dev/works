# 判断ログ

議論で到達した判断と、その理由・却下した代替案の台帳。
同じ論点を後で蒸し返さないために残す。新しいものほど上にある。

ここに書くのは**ユーザーと合意した判断**（方針・スコープ・生活の前提・複数案から選んだ設計）。
Claude が実装中に選んだ技術的な選択とハマりどころは `KNOWLEDGE.md`。やることは `TODO.md`。
追記は `/decide`。新しいエントリは下の `---` の直後に入れる（`/decide` がそうする）。

**このリポジトリは公開する前提なので、ユーザーの発言の原文は写さず要旨にとどめる。** 原文と計画の全体は ops に記録。

2026-10-19 以前の日付のエントリは、前身のサイト（非公開の保存用）の判断台帳から、このサイトに当てはまるものだけを要約して移したもの（末尾の「前身から引き継いだ判断」。T12）。
キャリアの情報にかかわる判断は移していない。コードのコメントにある「logs/decisions.md 2026-xx-xx」は、どれもこのファイルのエントリを指す。

1 エントリの形式（`/decide` と同じ。1 エントリ 1 判断）：

```
## YYYY-MM-DD <論点を一言で>

**論点**: 何を決めようとしていたか
**結論**: どう決めたか
**理由**: なぜその結論にしたか
**却下した代替案**: 検討して捨てた選択肢と、捨てた理由（なければ「なし」）
**確信度**: 高 / 中 / 低
**見直す条件**: この前提が崩れたら判断をやり直す、という条件（なければ「なし」）
```

## 2026-09-25 Astro（静的出力）でサイトを作り、リポジトリの直下に置く
